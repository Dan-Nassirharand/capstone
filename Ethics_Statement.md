## 1. Privacy summary

Data subjects are pilot engineers, the two members, and engineers whose code appears in a diff. No consumer record crosses any D0 to D2 arrow, and the recipe record has no author field. There are no sensor readings and no user uploads.

**Consent.** **N1:** before T11 and T12 the Advisor gives each pilot engineer a one-page notice listing the rows below that concern them (identity on each deletion, diffs sent to Copilot, session timing and ratings, free-text keep reason), the retention rule, and whom to tell to stop. The engineer opts in by written reply; no reply means no pilot. Withdrawal removes their IAM and repository access and deletes their session rows. Use is never treated as consent. Not yet issued; due with recruitment (M18, Jan 27). **N3:** product content or configuration with no personal data.

**At project end (M25, Apr 30, 2027).** The team hands everything to GE: it transfers the Terraform stacks and DynamoDB tables (audit tables, removal log, pilot recipe copy) to a GE-owned AWS account, or exports and deletes them, removes every team and pilot IAM identity, and records this in the final report. The team keeps no copy; laptops hold synthetic data only. After handoff, retention is GE's policy.

## 2. Security summary

**Git history search (2026-11-10).** All 52 commits on every branch (`git log --all -p`, 6,419 changed lines, 22 paths ever tracked), 14 patterns: AWS key IDs and secret names, private key blocks, GitHub, Slack, Google, and OpenAI-style tokens, `Authorization` headers, `password`/`secret`/`api_key` assignments, connection strings, URLs with credentials, ARNs with account IDs, default-credential phrases, and long hex strings. **0 matches.** No `.env`, key, `.tfvars`, or `.tfstate` file was ever tracked. Limits: compressed PDF text was not scanned, and GitHub's secret-scanning alerts needed a login; Dan checked the Security tab on 2026-11-10 and no alerts are reported; TC-025 re-reads them.

**Fixed.** Added [.gitignore](.gitignore) (none existed): `.env*`, keys, `*.tfstate`, `*.tfvars`, `.aws/`, build output. Two design gaps found are open (audit rows 4 and 6).

**Mechanisms.** _Authentication:_ IAM with SigV4, verified by API Gateway. _Token lifetime:_ C3 issues none; Identity Center sessions last **1 hour** (**TODO (Maxwell):** confirm and set it in the account or Terraform, T2), the CLI re-signs once, and AWS rejects signatures older than about 5 minutes. _HTTPS:_ the gateway endpoint is HTTPS-only, as are the GitHub calls; TLS on the gateway-to-load-balancer hop is not specified (**TODO (Maxwell, T2):** decide and record). _Rate limiting:_ stage throttle of **5 requests per second, burst 10** in Terraform, plus 200 IDs per request, one active run, and a 20 s deletion budget. _Authorization:_ a task role limited to the recipe and audit tables, and a typed `yes` before any delete. _At rest:_ DynamoDB encrypts all tables by default.
